Install on Android

  1. Tap Download for Android on your phone. The file is about 45 MB.
  2. Open the downloaded Pitchside.apk. If your phone asks, allow your browser or file manager to install unknown apps.
  3. Tap Install, then open Pitchside and set up your first tournament.
⚠️ When Pitchside arrives on Google Play, uninstall this version before installing the Play version. Your tournaments are saved on the phone, so set them up again or finish them first.
